# Archivio Leggi

Archivio delle leggi italiane approvate, modificate e abrogate dal 1990 che, per ognuna, risponde a una domanda: **a distanza di anni, ha ottenuto quello che prometteva?**

Progetto gratuito e non commerciale. Visione, metodo e stato dei lavori sono in [`docs/`](docs/).

## Struttura
- [`docs/`](docs/) — visione, schema dati, metodo di valutazione, fonti, stato e decisioni.
- [`ingest/`](ingest/) — ingestione dei dati (Normattiva, Camera, Senato, Istat).
